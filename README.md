# Starbucks Custom Journal (スタバカスタム手帳)

スターバックスのお気に入りカスタムを記録・管理・横長カフェカード風に画像保存できるWebアプリケーションです。

## 主な機能
- **タブ切り替え**: 「すべて表示」「お気に入りのみ」「ランキング（評価順）」
- **横長カフェカード風デザイン**:
  - 左側: ドリンク写真（未登録時はスタバ風アイコン）＋「★ 評価 / 10」ゴールドバッジ
  - 右側: メニュー名、ベースミルクタグ＆記録日、カスタム詳細、感想メモ
  - 上下: Starbucks Custom Journal / Created by うい
- **長押し画像保存**:
  - スマホでのタップ＆ホールド（長押し）やPCでの右クリックから直感的にカメラロール/写真へ保存
- **データ保存**: ブラウザの `LocalStorage` を利用した無料・安心のクライアント完結型設計

## 公開方法（Vercel）
`index.html` 単体で動作する静的サイト（Static Site）構成となっています。
GitHubリポジトリにプッシュしてVercelと連携するだけで、数分で無料公開が完了します。
